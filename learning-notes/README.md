# Living RAG 学习日志

这个目录用于记录开发 Living RAG 和后续 Agent Reliability Lab 过程中的每日学习内容、命令、问题、解决方案与复习清单。

## 使用约定

- 每天创建一份 `day-XX-主题.md`，例如 `day-01-project-foundation.md`。
- 记录重点是“我为什么这样做、遇到了什么问题、如何验证结果”，不只是粘贴代码。
- 每天完成开发后，补充“复习清单”和“下一天的起点”。
- 命令中的 API Key、真实密码和 `.env` 内容不写入日志。
