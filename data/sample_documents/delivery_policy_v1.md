## 1. 订单配送状态说明

订单配送状态包括但不限于：

| 状态 | 含义 |
| --- | --- |
| pending_payment | 等待支付 |
| paid | 已支付，等待出库 |
| shipped | 已发货，运输中 |
| delivered | 已签收 |
| cancelled | 已取消 |
| refunded | 已退款 |

## 2. 无理由退款与签收状态

1. 用户在订单状态为 `shipped` 或其他未签收状态时，不能发起无理由退货退款。
2. 用户应在商品实际签收后，根据当前有效的退款政策申请退货退款。
3. 若包裹在运输途中发生丢失、严重破损或确认无法送达，用户可联系在线客服发起物流异常处理；该处理不等同于无理由退货。

## 3. 偏远地区配送时效

1. 偏远地区包括但不限于高原、边境、海岛及承运商定义的偏远服务区域。
2. 偏远地区订单的预计配送时效可能比普通地区延长 3 至 7 个自然日。
3. 物流延迟本身不自动构成退款条件；客服应先核实物流轨迹、承运商异常记录和预计送达日期。
4. 若订单超过承运商承诺时效且无法继续履约，平台可按物流异常流程处理取消订单或退款。

## 4. 签收日期认定

1. 退款期限的起算依据是承运商物流系统记录的实际签收日期。
2. 用户主张的签收日期与物流记录不一致时，以承运商可核验记录为准；必要时由人工客服复核。
3. 用户拒收、代收或异常签收争议，应由客服记录处理结论后再决定退款路径。

## 5. 运费争议处理

1. 因平台或承运商责任导致的配送异常，相关运费处理由客服根据订单和物流证据决定。
2. 因用户地址填写错误、拒收或个人原因造成的额外费用，平台可不承担。
3. 涉及退货运费权益时，还应同时适用当前有效的退款政策和会员权益规则。
